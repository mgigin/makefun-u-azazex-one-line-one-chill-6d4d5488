One line of horror for the [One Line, One Chill](https://make.fun/bounty/u-azazex-one-line-one-chill-6d4d5488) bounty on make.fun: a single sentence, under 200 characters, that has to frighten a reader in one breath.

## The entry

> The parking ticket under my wiper was dated tomorrow, in my own handwriting, and all it said was: don't come back tonight.

A warning from tomorrow, in the reader's own hand — concrete, original, and the dread outlasts the line. No mirror, no doll, no basement.

## Run

```sh
node main.ts
```

The program is deterministic, uses no network and no dependencies. It validates the gate itself (1–200 UTF-8 characters, one line, not only whitespace) and writes the entry to `/output/entry.txt`.
